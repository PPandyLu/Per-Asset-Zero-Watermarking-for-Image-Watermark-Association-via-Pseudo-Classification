# Collective blind review

Six reviewers produced one consensus label per panel: match, uncertain or non-match. The [200-panel representative set](representative_200/ratings.csv) measures agreement. The [198-panel directed audit](directed_audit_198/ratings.csv) examines 163 negative-control false alarms and 35 cases of model-configuration disagreement. The two sampling designs answer different questions. Eight underlying cases occur in both sets and are identified in [the overlap table](cross_set_overlap.csv).

Each table joins the anonymized case identifier to the final consensus label and the model decision. The case metadata and answers are public for analysis after completion of the blind review. Extract the corresponding panels archive beside the table and open the image named in the panel path column.
